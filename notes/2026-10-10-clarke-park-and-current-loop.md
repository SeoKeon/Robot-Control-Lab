# 2026-10-10 Clarke·Park 변환과 전류 루프 — 3상 전류를 직류 두 개로 만들어 제어하기

<!-- 오늘 실측(정지 시 id 0.0 / iq 100.0 mA, 각도 지연 0.87 ms)을 예로 쓴다 -->

## 왜 찾아봤나

전압 모드 정류는 잡으면 전류가 V/R 까지 커졌다. 전류를 직접 제어하려면 세 상의 사인파
전류를 "목표값과 비교할 수 있는" 형태로 바꿔야 한다. 그게 Clarke·Park 변환이고, 그 위에
제어기(PI)를 얹는 게 전류 루프다. 오늘 실험 로그 4편의 이론 쪽 정리다.

## 핵심

### 1. 왜 변환이 필요한가 — 사인파는 목표로 삼기 어렵다

모터가 돌면 세 상 전류는 회전 속도에 맞춰 출렁이는 사인파다. "U상 전류가 100 mA 가 되게"
는 의미가 없다 — 매 순간 값이 바뀌어야 하니까. 그런데 **로터와 같이 도는 좌표계**에서
보면, 정상 상태의 전류는 **움직이지 않는 상수 두 개**가 된다. 상수는 PI 로 쉽게 맞출 수 있다.

```
세 상 (iU, iV, iW)   --Clarke-->   고정 2축 (iα, iβ)   --Park(θe)-->   회전 2축 (id, iq)
 120도씩 벌어진 사인파           90도 벌어진 사인파 2개             로터에 붙어 도는 직류 2개
```

### 2. Clarke — 3개를 2개로 (정보 손실 없이)

세 상 전류의 합은 항상 0 이다(키르히호프). 그러니 독립인 값은 2개뿐이다.
진폭 불변형(크기가 상전류 진폭과 같게 나오는 형태):

```
iα = (2·iU − iV − iW) / 3
iβ = (iV − iW) / √3
```

오늘 코드는 세 상을 다 써서 노이즈를 평균했다. 두 상만 써도 되지만(iW = −iU − iV),
세 상을 쓰면 한 채널의 영점 오차가 덜 튄다. **세 상 합 ≈ 0** 은 그 자체로 센싱이 맞다는
공짜 검증이다 (오늘 정지 벡터에서 −1.6 ~ −10 mA, 1 count 미만).

### 3. Park — 로터 각도로 돌린다

```
id =  iα·cos θe + iβ·sin θe
iq = −iα·sin θe + iβ·cos θe
```

- **d축** = 자석 N 방향. 여기로 흐르는 전류는 토크를 안 만들고 열만 낸다 → **id = 0** 이 목표
- **q축** = d 에서 90도. 토크 τ = 1.5 · 극쌍수 · ψ · iq (오늘 값: 약 0.086 N·m/A)

θe 가 틀리면 전부 틀린다. 오늘 관측 순서가 그걸 보여준다:
- 정지 시 id ≈ 0 → 각도·오프셋·변환이 맞다 (각도 오차가 있어도 정지 시에는 효과가 없다는
  점도 함께 봐야 한다 — 그래서 "회전 중" 검증이 따로 필요했다)
- 회전 중 id ≠ 0, 방향 무관 + → 오프셋이 아니라 **각도 지연** (오프셋 오차는 방향에 따라
  부호가 뒤집힌다)
- 지연 τ 를 θ + ω·τ 로 보정 → id 45 → 2~4 mA ([dq 로그](../log/2026-10-10-dq-observation-and-encoder-lag.md))

### 4. 전류 루프 — 측정한 플랜트로 설계한다

이 모터의 전압 방정식 (정상상태, L 무시 — 짐벌모터는 L/R 이 루프 주기보다 짧다):

```
Vq = R·iq + ψ·ω        (ψ·ω = 역기전력)
Vd = R·id
```

여기서 바로 제어기가 나온다:

```
Vq = R·iq_지령 + ψ·ω  +  적분기(iq_지령 − iq)
     \_____ 피드포워드 _____/    \___ 나머지 보정 ___/
```

- **피드포워드**: 모델로 필요한 전압을 미리 계산한다. 모델이 맞으면 적분기는 할 일이 없다
- **적분기**: 모델 오차(R 의 온도 변화, ψ 오차 등)만 천천히 메운다. 게인을 작게 잡을 수 있어
  **전류 노이즈(샘플 σ ≈ 30 mA)에 둔감**하다
- P 항을 안 쓴 이유: 플랜트가 거의 즉시 반응(저항)이라 P 는 노이즈를 그대로 전압으로
  내보내는 역할만 한다

### 5. 포화 — 전압은 무한하지 않다

인가 전압은 버스 전압으로 막힌다 (오늘은 안전하게 m ≤ 0.40 = 상 진폭 2.4 V).
무부하로 토크를 주면 반드시 역기전력이 한계에 닿는다(오늘 360 rpm). 그때:

- **anti-windup**: 포화 중에도 적분기가 계속 쌓이면, 포화가 풀릴 때 쌓인 만큼 튄다.
  포화 중에는 적분을 멈춘다
- **어느 축을 포기할 것인가**: 오늘은 d·q 를 같은 비율로 줄이고 둘 다 적분을 멈췄다 →
  포화 중 id 가 −9 ~ −14 mA 로 벗어났다. 표준은 **d 를 먼저 지키고 남는 전압을 q 에**
  (id 가 무너지면 같은 전류로 토크가 줄고 열만 늘어난다)

### 6. 상전류 ≠ 전원 전류

전원공급장치는 **버스 전류**를 보여준다. 모터 몫은 전력으로 환산해야 한다:

```
P = 1.5 · (Vd·id + Vq·iq)      (진폭 불변형)
버스 전류 = P / V_bus  (+ 보드 자체 소비)
```

오늘: 잡았을 때 모터 전류 159 → 100 mA(1.6배)인데 전원 표시는 0.16 → 0.14 A. 보드 자체
소비 약 0.12 A 위에 모터 몫 36 → 15 mA 가 얹힌 것이다.

## 실습 연결

- 다음 단계 **속도 루프**는 이 전류 루프를 "토크를 내는 부품"으로 쓴다. 속도 PI 의 출력이
  iq 지령이 된다 → [PID 캐스케이드 노트](2026-07-22-pid-cascade-structure.md)
- 캐스케이드의 규칙: **안쪽 루프가 바깥보다 충분히(5~10배) 빨라야** 바깥 루프가 안쪽을
  "즉시 반응하는 부품"으로 볼 수 있다. 오늘 전류 루프는 수 ms 로 지령을 따라가므로, 속도
  루프는 그보다 느린 수십 ms 대역으로 설계한다
- 직접 해볼 것: 피드포워드를 끄고(적분기만) 같은 브레이크 테스트를 해보면, 적분 게인이
  작을 때 지령을 따라가는 데 얼마나 오래 걸리는지 보인다
