# 2026-10-10 속도 루프 설계 — 관성·토크 상수로 PI 게인 정하기

<!-- 오늘 실측(J ≈ 5e-6, Kt ≈ 0.086, 대역폭 5/10/15 Hz 비교, 1 ms 계단 응답)을 예로 쓴다 -->

## 왜 찾아봤나

전류 루프 위에 속도 PI 를 얹으면서 게인을 "적당히" 고르지 않고 플랜트에서 계산하고 싶었다.
그리고 실험에서 나온 세 가지 — 한 바퀴마다 출렁이는 속도, 대역폭을 올리니 줄어든 것, 이론보다
큰 오버슈트 — 를 설명할 틀이 필요했다. [속도 루프 로그](../log/2026-10-10-speed-loop.md)의 이론 쪽.

## 핵심

### 1. 캐스케이드와 대역폭 분리

```
ω_ref → [속도 PI] → iq_ref → [전류 루프] → iq → Kt → 토크 → [1/(J·s)] → ω
```

안쪽 루프가 바깥보다 **5~10배 이상 빠르면**, 바깥 루프는 안쪽을 "지령이 곧바로 나오는 부품"
(iq = iq_ref)으로 보고 설계할 수 있다. 오늘 전류 루프는 1~2 ms 에 지령을 따라간다
(대역폭 약 100 Hz 이상) → 속도 루프는 10~20 Hz 이하로 둔다.

그러면 속도 루프가 보는 플랜트는 단순하다:

```
J · dω/dt = Kt · iq − τ_부하         →   ω(s) / iq(s) = Kt / (J·s)     (적분기 하나)
```

### 2. 게인 계산 — 원하는 대역폭에서 거꾸로

PI 제어기 `iq = Kp·e + Ki·∫e`. 개루프 전달함수:

```
L(s) = (Kp·s + Ki) / s  ×  Kt / (J·s)
```

적분 영점(Ki/Kp)을 교차 주파수 ωc 보다 충분히 아래에 두면, ωc 근처에서 |L| ≈ Kp·Kt / (J·ωc).
이게 1 이 되는 곳이 교차 주파수:

```
Kp = J · ωc / Kt          Ki = Kp · ωc / 4      (영점을 ωc/4 에)
```

오늘 값: J = 5e-6, Kt = 0.0855 → 15 Hz(ωc = 94 rad/s) 에서
Kp = 5.5 mA/(rad/s), Ki = 0.13 A/rad. **물리 단위가 붙는다**: 속도가 1 rad/s(약 10 rpm) 틀리면
iq 를 5.5 mA 더 낸다.

> J 가 틀리면 실제 대역폭이 그 비율만큼 달라진다. 그래서 대역폭 비교 실험으로 결과를 확인했다.

### 3. 외란 억제 — 왜 5 Hz 로는 부족했나

회전 위치마다 다른 부하 τ_d 가 걸리면, 정상상태에서 비례 항만으로 버틸 때 속도 오차는

```
Δω ≈ τ_d / (Kp · Kt)
```

오늘 한 바퀴 부하 약 ±1 mN·m:
- 5 Hz: Kp·Kt = 1.6e-4 N·m/(rad/s) → Δω ≈ 6 rad/s ≈ 60 rpm (관측 sd 52)
- 15 Hz: Kp·Kt = 4.7e-4 → Δω ≈ 2 rad/s ≈ 20 rpm, 그리고 적분기가 저주파 성분을 더 누른다 (관측 sd 5)

외란의 주파수(100 rpm 에서 1.7 Hz)가 대역폭보다 **충분히 아래**에 있어야 잘 눌린다. 5 Hz 는
외란과 겨우 3배 차이였다. **iq 출렁임은 게인과 무관하게 남는다** — 부하는 그대로니 토크로 맞받을
수밖에 없고, 게인은 "얼마나 작은 속도 오차로 그 토크를 내느냐"를 정한다.

대역폭을 무한정 올릴 수 없는 이유:
- **속도 측정 노이즈 × Kp** 가 iq 지령 노이즈가 된다 (엔코더 4096 CPR, 1.9 kHz 차분 →
  1 count 가 약 28 rpm. 5 ms 필터로 평활)
- **필터와 루프 지연이 위상을 깎는다** — 다음 절
- 대역폭 분리가 무너진다 (전류 루프보다 충분히 느려야 한다)

### 4. 계단 응답과 오버슈트 — PI 영점의 몫

J 가 정확하고 지연이 없다고 하면 폐루프는

```
ω/ω_ref = (ωc·s + ωc²/4) / (s + ωc/2)²
```

극점은 겹근(임계감쇠)인데도 **영점 때문에** 오버슈트가 생긴다. 계단 응답:

```
y(t) = 1 − e^(−ωc·t/2) + (ωc·t/2)·e^(−ωc·t/2)
최고점 t = 4/ωc 에서 y = 1 + e^(−2) ≈ 1.135   → 오버슈트 13.5%
```

15 Hz: 최고점 42 ms, 13.5%. 실측은 감속 계단 13~18%(이론과 맞음), 가속 계단 46~54%.
차이의 후보:

- **5 ms 속도 필터**: ωc 에서 위상 지연 atan(94 × 0.005) ≈ 25도. 이론 위상 여유 76도
  (−180 + atan(4))가 약 50도로 → 오버슈트 증가
- **회전 위치 부하**가 계단 도중에 섞임
- 기록된 속도도 필터를 거친 값이라 실제 최고점은 더 높다

줄이는 정석 (나중에 해볼 것):
- **지령을 램프로** — 가속도를 제한한 궤적. 위치 루프에서 어차피 필요하다
- **setpoint weighting**: 비례 항을 `Kp·(b·ω_ref − ω)` 로, b < 1. 지령 계단이 비례 항을 직접
  때리지 않게 한다 (b = 0 이면 I-P 제어)
- 적분 영점을 더 낮게 (ωc/4 → ωc/8): 오버슈트는 줄지만 외란 회복이 느려진다

### 5. 출력 제한과 anti-windup

iq 지령은 ±150 mA 로 제한했다(모터·전원 보호). 한계에 붙어 있는 동안 적분기가 계속 쌓이면,
한계가 풀린 뒤 쌓인 만큼 반대로 갚느라 크게 튄다. 오늘 쓴 방법 (조건부 적분):

```
출력이 한계에 닿아 있고 + 오차가 한계를 더 미는 방향이면 → 적분 정지
```

브레이크 테스트에서 1.6 초 한계에 붙어 있다 놓았을 때 210 rpm 까지만 튀고 0.2 초에 안착.
안 막았다면 ≈ 3 A 어치가 쌓였을 것이다 (로그 §3).

### 6. 같은 구조가 다시 나온다

전류 루프 — 속도 루프 — 위치 루프 모두 **"플랜트를 재고 → 대역폭을 정하고 → 게인을 계산하고 →
제한과 anti-windup 을 붙이는"** 같은 순서다. 다음 위치 루프의 플랜트는 `θ = ∫ω` (또 적분기 하나)
이고, 속도 루프가 그 안쪽 부품이 된다.
