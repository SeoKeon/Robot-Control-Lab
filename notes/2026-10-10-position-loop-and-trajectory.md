## 왜 찾아봤나

속도 루프 위에 위치 루프를 얹으면서 세 가지를 정리하고 싶었다: 게인은 어떻게 정하나, 왜 목표를
계단으로 주지 않고 궤적으로 주나, 오늘 본 "정지 직전 끈적임"과 "놓으면 넘어감"은 무엇인가.
[위치 루프 로그](../log/2026-10-10-position-loop.md)의 이론 쪽.

## 핵심

### 1. 플랜트는 또 적분기 하나

속도 루프가 충분히 빠르면, 위치 루프가 보는 플랜트는 `θ = ∫ω` 다:

```
θ(s) / ω_ref(s) ≈ 1/s            (속도 루프가 ω = ω_ref 를 즉시 만든다고 볼 때)
```

그래서 P 제어만으로 폐루프가 1차 시스템이 된다:

```
ω_ref = Kp·(θ_ref − θ)   →   θ/θ_ref = Kp / (s + Kp)     시정수 1/Kp
```

오늘 Kp = 2π·4 = 25 /s → 시정수 40 ms. 대역폭 분리 규칙대로 속도 루프(15 Hz)의 1/4 정도에 뒀다.
30도 계단을 줬을 때 지수함수로 다가가며 0.4도만 넘어간 게 이 1차 응답이다.

### 2. 정지 오차가 0 이 되는 이유 — 적분기는 안쪽에 있다

위치 루프에 적분기가 없어도 된다. 일정한 부하 τ_d 가 걸려 있어도, 정지 상태(ω = 0)가 유지되려면
속도 PI 의 입력 `ω_ref − ω = Kp·e` 가 0 이어야 한다(아니면 속도 적분기가 계속 변한다). 따라서
**e = 0**. 부하를 버티는 토크는 속도 적분기가 쥐고 있다.

같은 이유로, 밀린 채로 붙잡고 있으면 적분기가 계속 쌓여 **결국 iq 한계까지** 간다 (오늘 10도만
밀어도 0.2 s 뒤 150 mA). 정적 강성이 무한대인 셈 — 단, 토크 한계까지만.

### 3. 궤적 — 왜 계단을 주지 않나

사다리꼴 속도 프로파일: 등가속(a_max) → 등속(v_max) → 등감속. 거리가 짧으면 등속 없이 삼각형.

```
가속 시간 ta = v_max / a_max
등속 시간 tc = (거리 − v_max²/a_max) / v_max     (음수면 삼각형: v_peak = √(거리·a_max))
```

궤적이 주는 세 가지:

| | 계단 | 궤적 |
|---|---|---|
| 출발 순간 토크 | 최대치가 처음에 (오늘 72 mA) | 가속도로 정해짐 (오늘 최대 54 mA) |
| 도착 시각 | 지수함수 — 정확히는 "영원히" | 계획한 시각에 도착 |
| 여러 축 동기 | 축마다 제각각 | 같은 시간으로 맞출 수 있음 |

로봇팔에서는 세 번째가 결정적이다. 그리고 궤적이 있으면 **피드포워드**를 쓸 수 있다:

```
ω_ref = v_궤적 + Kp·(θ_궤적 − θ)        속도 피드포워드
iq_ff = J·a_궤적 / Kt                   가속 피드포워드
```

피드포워드가 "해야 할 일"을 미리 하고, 피드백은 오차만 메운다 — 전류 루프의 `R·iq + ψ·ω`
피드포워드와 같은 생각이다.

### 4. Stick-slip — 정지 마찰이 만드는 끈적임

정지 마찰(움직이기 시작하는 힘)이 운동 마찰(굴러가는 힘)보다 크면:

```
① 멈춘다 → 오차가 남는다
② 적분기가 쌓인다 (토크가 서서히 오름)
③ 정지 마찰을 넘는 순간 풀린다 — 그런데 운동 마찰은 더 작다 → 남는 토크가 로터를 밀어
④ 목표를 지나친다 → ① 로
```

오늘: 복귀 이동 끝 7.9도에서 멈춤 → 풀리며 −4.2도 → 또 멈춤 → 약 1.5 s 에 안착.
대책 (정석들):
- **마찰 보상 피드포워드**: 움직이려는 방향으로 정지 마찰만큼 토크를 미리 (마찰을 측정해야 함)
- **데드밴드**: 오차가 ±0.2도 안이면 적분을 멈춤 — 끈적이며 오가는 것(hunting)을 막는 대신 그만큼 오차 허용
- 기구 개선 — 결국 제일 확실하다

### 5. 놓았을 때 넘어가는 양 — 저장된 적분기

밀려 있는 동안 속도 PI 출력은 iq 한계에 붙는다. `한계 = 비례 항 + 적분기` 에서 적분기 몫이
**저장된 토크**다. 놓는 순간 이 토크가 그대로 남아 로터를 밀고, 목표를 지날 때까지 다 갚지 못해
넘어간다. anti-windup 이 적분기를 한계 근처에서 멈춰두기 때문에 저장량은 밀린 거리와 무관하게
비슷하다 → 오늘 넘어간 양이 8~19도로 거의 일정했던 이유.

이건 "**밀리면 끝까지 버티기**(강한 적분)"와 "**놓았을 때 얌전히 돌아오기**"의 거래다. 로봇
관절에서는 상황에 따라 일부러 강성을 낮추기도 한다(임피던스 제어 — 나중 주제).

## 실습 연결

- 코드: `traj_plan()` / `traj_eval()` (궤적), `run_loop_body()` 의 `MODE_POS` 블록
- 직접 해볼 것:
  - `KP_POS` 를 2배(8 Hz)로 → 이동 중 오차는 줄지만 정지 떨림이 늘어나는지
  - 가속 피드포워드를 빼고(iq_ff = 0) 이동 중 최대 오차 비교 → 피드포워드의 몫이 보인다
  - `POS_WLIM` 을 60 rpm 으로 → 놓았을 때 넘어가는 양이 줄어드는지
  - 모터를 손으로 천천히 돌려 걸리는 곳 찾기 → 오늘 끈적인 0~20도 구간과 같은 곳인가
- 스스로 답해볼 질문: 위치 루프에 적분기를 하나 더 넣으면 무슨 일이? 궤적의 가속도를 2배로
  올리면 가속 피드포워드는 몇 mA 가 되고, iq 한계(150 mA)까지 여유는 얼마나?
