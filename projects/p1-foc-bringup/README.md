# p1-foc-bringup — 모터 첫 회전과 FOC

**목표**: 2804 짐벌모터를 실제로 돌린다. 오픈루프 첫 회전 → 전류 센싱 →
클로즈드루프 FOC. 완료 기준은 **전류 루프가 닫힌 상태로 속도 지령을 따라가는 것**.

- `src/foc_bringup/` — 실험 코드
- `data/` — 측정 데이터 (전류 파형, 속도 응답 등)
- `docs/` — (핀맵은 [p0-setup/docs/pinmap.md](../p0-setup/docs/pinmap.md) 에 있다)

## 안전 — 매번 확인

| 항목 | 값 | 왜 |
|---|---|---|
| 전원 전류 리밋 | **0.8~1A** | 정상 최대 0.57A(12V/21Ω)보다 위, 션트-스루보다 훨씬 아래 |
| 시작 듀티 | **20~30%** | 10%는 토크가 약해 안 움직일 수 있다 |
| 부하 | 없음 | 무부하, 모터 고정만 |
| 정지 벡터 유지 | 1~2초 | DC 가 권선에 계속 흘러 열이 쌓인다 |

⚠️ **TIM1_BKIN 이 MCU 에 연결돼 있지 않다.** 하드웨어 과전류 차단 경로가 없으므로
**전원공급장치의 전류 리밋이 유일한 실질 보호장치다.**

⚠️ **게이트 드라이버 EN 핀이 없다.** 6개 PWM 만으로 제어되므로 소프트웨어로 출력을
끊는 수단이 없다. 리셋 직후 MOE off / 듀티 0 으로 시작할 것.

### 데드타임 유도

L6387E 데이터시트 Table 5 (AC operation, VCC=15V, TJ=25°C, 전부 Typ. 값):

| 파라미터 | 값 |
|---|---|
| `ton` 턴온 전파지연 | 110 ns |
| `toff` 턴오프 전파지연 | 105 ns |
| `tr` 상승시간 (CL=1nF) | 50 ns |
| `tf` 하강시간 | 30 ns |
| 출력 sink/source 전류 | 400 mA / 650 mA |

Figure 6/7 (Ton/Toff vs 온도) 축이 250 ns 까지 그려져 있다 — 온도에 따라 typ 보다 커진다.

**상단이 완전히 꺼진 뒤에 하단이 켜져야 한다:**

```
DT_min ≳ (toff_최대 + MOSFET 게이트 방전) − ton_최소
       ≈ (약 200 + 약 250) − 약 70
       ≈ 380 ns
```

MOSFET 게이트 방전은 STL180N6F7 의 Qg 를 driver sink 전류(400 mA)로 나눈 추정치다
(정확한 값은 STL180N6F7 데이터시트 필요).

**첫 브링업은 ×2 여유를 두고 1000 ns 로 잡는다.** 근거:
- `TIM1_BKIN` 이 MCU 에 연결돼 있지 않아 **하드웨어 과전류 차단이 없다** → 보수적으로
- 20 kHz 주기 50 µs 중 1 µs = **2%** 뿐이라 변조 성능 손실이 사실상 없다

### GPIO 출력 속도는 Low 로 (6개 전부)

`PC13` 은 CubeMX 에서 **`Low` 밖에 선택할 수 없다.** PC13/14/15 는 백업 도메인
(RTC/TAMP/WKUP) 쪽 핀이라 구동 능력이 제한된다. 버그가 아니다.

**문제되지 않는다.** 회로도에서 확인한 `L6387ED` 결선:

```
L6387ED (상마다 하나 — U9/U10/U11)
  1 LIN  ← MCU 연결 (로직 입력, 수 pF CMOS)
  2 HIN  ← MCU 연결
  5 LVG  → MOSFET 게이트 (드라이버가 sink 400mA / source 650mA 로 구동)
  7 HVG  → MOSFET 게이트
```

MCU 는 MOSFET 게이트가 아니라 **드라이버의 로직 입력**만 흔든다. 부하가 수 pF 이므로
Low 속도로도 에지는 수 ns 다. 데드타임 예산은 드라이버 전파지연(105/110 ns)과
MOSFET 게이트 충·방전이 지배하고, MCU 슬루율은 그 안에서 무시할 수준이다.

→ **6개 핀 전부 Low 로 통일한다.** 절대 속도보다 **채널 간 편차(skew)** 가
중요하고, PC13 이 Low 고정이니 나머지도 맞추면 U/V/W 가 동일 조건이 된다.

> PC13 은 `TIM1_BKIN` 도 지원하는 핀이지만 여기선 CH1N 으로 쓴다.
> 어차피 보드에 BKIN 배선이 없어 무관하다.

### DTG 레지스터 환산 (RM0440, TIM1 BDTR)

TIM1 clk 170 MHz, CKD=1 → `t_DTS` = **5.882 ns**

| DTG[7:5] | 식 | 범위 |
|---|---|---|
| `0xx` | DT = DTG[7:0] × t_DTS | 0 ~ 747 ns |
| `100` | DT = (64 + DTG[5:0]) × 2 × t_DTS | 753 ~ 1118 ns |

1000 ns 는 첫 범위를 넘으므로 `100` 인코딩을 쓴다:

```
(64 + 21) × 2 × 5.882 ns = 85 × 11.765 = 1000.0 ns
DTG = 0b100_10101 = 0x95 = 149
```

> 대안: `DTG = 127` (0x7F) → 747 ns. 최소값(380 ns)의 약 2배로 이것도 방어 가능하다.
> 스코프로 상·하단 게이트 파형을 실측한 뒤 줄이는 게 정석이다.
