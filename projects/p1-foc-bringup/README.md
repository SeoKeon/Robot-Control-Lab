# p1-foc-bringup — 모터 첫 회전과 FOC

**목표**: 2804 짐벌모터를 실제로 돌린다. 오픈루프 첫 회전 → 전류 센싱 →
클로즈드루프 FOC. 완료 기준은 **전류 루프가 닫힌 상태로 속도 지령을 따라가는 것**.

- `src/foc_bringup/` — 실험 코드
- `data/` — 측정 데이터 (전류 파형, 속도 응답 등)
- `docs/` — (핀맵은 [p0-setup/docs/pinmap.md](../p0-setup/docs/pinmap.md) 에 있다)

## 모터

| | |
|---|---|
| 모델 | 2804 짐벌모터 (AS5600 내장) |
| 슬롯/극 | 12N14P → **pole pairs = 7** |
| 전기각 | θe = 7 × θm. 전기 360° = 기계 51.43° |
| 상간 저항 | **21Ω** 실측 (U-V, V-W, W-U 동일) → Y결선 상저항 10.5Ω |
| 코깅 주기 | LCM(12,14) = 84 → 4.29° |

이론 정리는 [2026-08-20 로그](../../log/2026-08-20-motor-anatomy-and-board-bringup.md) 참고.

## 안전 — 매번 확인

| 항목 | 값 | 왜 |
|---|---|---|
| 전원 전류 리밋 | **0.8~1A** | 정상 최대 0.57A(12V/21Ω)보다 위, 션트-스루보다 훨씬 아래 |
| 시작 듀티 | **20~30%** | 10%는 토크가 약해 안 움직일 수 있다 |
| 부하 | 없음 | 무부하, 모터 고정만 |
| 정지 벡터 유지 | 1~2초 | DC 가 권선에 계속 흘러 열이 쌓인다 |

⚠️ **TIM1_BKIN 이 MCU 에 연결돼 있지 않다.** 하드웨어 과전류 차단 경로가 없으므로
**전원공급장치의 전류 리밋이 유일한 실질 보호장치다.**

⚠️ **게이트 드라이버 EN 핀이 없다.** 6개 PWM 만으로 제어되므로 소프트웨어로 출력을
끊는 수단이 없다. 리셋 직후 MOE off / 듀티 0 으로 시작할 것.

## 진행 단계

- [ ] TIM1 상보 PWM 6채널 + 데드타임 (CubeMX)
- [ ] (a) 정지 벡터 — 로터가 한 위치에 고정되는지
- [ ] (b) 전기각 천천히 회전 — 첫 회전. 떨기만 하면 두 상 교체
- [ ] (c) 주파수 상승 — 탈조 한계 확인
- [ ] ADC + 내장 OPAMP 3션트 전류 센싱
- [ ] Clarke/Park → 전류 루프 → FOC
- [ ] AS5600 엔코더 (I2C, PB6/PB7 가능성 확인 필요)
