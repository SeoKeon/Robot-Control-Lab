## 새 세션 시작 방법

Cowork 작업 폴더에 이 문서와 아래 파일 2개를 넣고, 첫 메시지로 이 문서를 읽고 이어서 진행하라고 요청하면 됩니다.

| 파일 | 내용 | 용도 |
| --- | --- | --- |
| foc\_test\_stand\_cq.zip | foc\_test\_stand.py, out/ 폴더(부품별 STEP·STL, assembly.step), asm.png | 원본 코드와 결과물 |
| foc\_test\_stand\_A1mini.3mf | 부품 8개를 180×180 베드에 배치한 출력 파일 | Bambu Studio에서 바로 슬라이스 |

이전에 받은 OpenSCAD 버전(foc\_test\_stand.scad 등)은 ESC1 치수가 틀린 구버전이라 쓰지 않습니다.

첫 메시지 예시:

> 작업 폴더의 인수인계 문서를 읽고 FOC 테스트 거치대 작업을 이어가줘. 답변은 한국어로 해줘. 먼저 foc\_test\_stand.py를 실행해서 out/ 결과물이 다시 만들어지는지 확인해줘.

## 하드웨어 구성

모터 1개를 ESC1 보드 1장으로 FOC 제어하는 구성이며, 배선은 사용자가 이미 완료했습니다.

| 부품 | 모델 | 치수·사양 | 비고 |
| --- | --- | --- | --- |
| 모터 | 2804 짐벌 BLDC | 외경 약 35 mm, 높이 약 15\~19.5 mm, 중공축 내경 5.4\~6.5 mm(제품마다 다름) | 바닥 4홀 패턴 미확인 |
| 엔코더 | AS5600 브레이크아웃 (TENSTAR) | 22.5 × 22.9 mm, 칩은 보드 중앙, 모서리 구멍 4개 | 별도 보드 + 자석 따로 |
| 자석 | 직경방향 착자 | 6 × 2.5 mm (표준) | 중공축 아래에 플러그로 고정 |
| 드라이버 | B-G431B-ESC1 (STM32G431CB) | 30 × 41 mm (ST-LINK 도터보드 포함), 고정 구멍 없음 | 모터 1개 전용 |
| 프린터 | Bambu Lab A1 mini | 빌드 180 × 180 × 180 mm | PLA 사용 |

AS5600 핀 배치: 위쪽 4핀 DIR / SCL / SDA / GPO, 아래쪽 3핀 VCC / OUT / GND. VCC는 3.3V.

ESC1에서 AS5600은 I2C로 연결하며, 홀/엔코더 패드의 PB7·PB8을 I2C로 씁니다. 이 핀을 쓰면 시리얼 디버깅 핀과 충돌할 수 있어 보드 설정 수정이 필요할 수 있습니다. 참고: SimpleFOC 포럼 "B-G431B-ESC1: Beginner guide + I2C guide".

제어 관련 메모: AS5600 I2C는 저속 위치·토크 제어에 적합하고 고속 회전에는 약합니다. ESC1은 대전류용이라 1A급 2804에선 전류 센싱 해상도가 거칠 수 있어, 처음엔 전압 모드 토크 제어로 시작하는 걸 권장했습니다.

## 작업 환경과 규칙

도구 조합은 VS Code + OCP CAD Viewer + CadQuery + FreeCAD + AI로 확정했습니다. 사용자의 설치 완료 여부는 아직 확인되지 않았습니다.

| 도구 | 역할 |
| --- | --- |
| CadQuery (Python) | AI와 함께 파라메트릭 모델을 코드로 작성, STEP·STL 출력 |
| VS Code + OCP CAD Viewer | 코드 실행 후 3D 모델 확인 (`show(asm)`) |
| FreeCAD | STEP을 열어 모깎기 등 마무리 미세조정 |
| Bambu Studio | 3MF·STEP을 슬라이스해 A1 mini로 출력 |

설치 순서: Python 3.12 → VS Code + Python·OCP CAD Viewer 확장 → 프로젝트 폴더에 `python -m venv .venv` → `pip install cadquery ocp_vscode` → FreeCAD 1.0 이상.

작업 흐름과 규칙:

1. 구조·치수 변경은 CadQuery 코드 단계에서 끝낸다. 숫자는 파일 상단 파라미터로만 관리한다.
2. FreeCAD 수정은 코드로 되돌아가지 않는 한 방향 작업이다. 중요한 변경을 FreeCAD에서 했다면 코드에도 반영한다.
3. 부품을 만들 때마다 STEP(편집용) + STL + A1 mini 배치 3MF를 함께 제공한다. 모든 부품은 서포트 없이 출력되는 방향으로 놓는다.
4. 슬라이싱된 G-code(.gcode.3mf)는 만들지 않는다. 기기 프로파일 재현이 불확실하고 프린터 손상 위험이 있어 슬라이스는 사용자가 Bambu Studio에서 한다.
5. 결과물은 렌더링 이미지로 확인시켜 주고, 사용자가 실측값을 주면 파라미터에 반영한다.

## 현재 결과물: 테스트 거치대

모터를 타워 위 모터판에 올리고, AS5600이 타워 안에서 모터 바닥의 자석을 올려다보며, 옆 트레이에 ESC1을 케이블타이로 묶는 구조입니다. 베이스는 112 × 58 mm, 모터판 윗면 높이 34 mm입니다. 아직 출력·조립 전입니다.

| 부품 | 설명 |
| --- | --- |
| base | 바닥판 + 타워(46 mm 사각, 높이 26 mm) + 캐리어 기둥 2개 + ESC 트레이(43 × 32 mm 안쪽) + 작업창·케이블창·케이블타이 슬롯·책상 고정 구멍 |
| motor\_plate | 방사형 슬롯 4개(M2.5, 폭 2.8)로 4홀 피치 12\~25 mm 대응, 중앙 12 mm 구멍, 모서리 M2.5 4개로 타워에 체결, 아랫면에 AS5600 나사머리 자리 4곳 |
| sensor\_carrier | AS5600 정사각 포켓 23.6 mm, 헤더 통과 슬롯 2개(11 × 4.4), 대각 M2.5 셀프태핑 2개로 보드 고정(와셔 불필요), 기둥 M2.5 나사머리 자리 |
| spacers | 0.4 / 0.6 / 1.0 mm 각 2개(바깥 6, 안 2.9), 기둥 위에 끼워 센서를 올림. 기본 간격 2.5 mm → 최소 0.5 mm |
| magnet\_plug\_m4\_4.5 / 4.7 / 4.9 (기본), m6\_\* | 중공축(실측 내경 4.7, 회전함) 아래에 압입하는 자석 홀더, 축 3종 (노치 1·2·3개로 구분). m4는 AS5600 동봉 자석 4 × 1.9, m6은 6 × 2.5용. 머리 높이 3.7 mm로 같아서 서로 호환. 자석은 머리 바닥 홈에 순간접착제 |
| indicator | 회전자 윗면에 M2 4개로 고정하는 30° 눈금 표시판, 두께 3 mm. 구멍 4개로는 1개만 맞아서 대각선 십자 슬롯(배치 원 지름 8\~17 mm, 폭 2.6)으로 변경 |

핵심 파라미터 (foc\_test\_stand.py 상단):

| 이름 | 값 | 의미 |
| --- | --- | --- |
| SENSOR\_W / SENSOR\_L | 22.7 / 23.1 mm | AS5600 보드 크기 (실측, 판매 페이지보다 큼) |
| SENSOR\_HOLE\_PITCH | 16.0 mm | 보드 구멍 중심 간격 (실측) |
| MOTOR\_D | 34.4 mm | 모터 외경 (실측) |
| HEADER\_ROW\_Y | 6.5 mm | 보드 중심\~헤더 줄 거리 |
| ESC\_L / ESC\_W | 41 / 30 mm | ESC1 크기 (ST 공식) |
| SHAFT\_IDS | 4.5, 4.7, 4.9 mm | 자석 플러그 축 내경 후보 (실측 4.7) |
| SLOT\_R\_MIN / MAX, SLOT\_W | 6 / 12.5 mm, 2.8 mm | 모터 고정 슬롯 범위 (M2.5, 실측 홀 원 지름 약 19.8) |
| TOWER\_H, MAG\_GAP | 26 mm, 2.5 mm | 타워 높이, 스페이서 없을 때 칩\~자석 간격 (기둥 높이는 여기서 계산) |

높이 관계: 모터 바닥이 평평(축 돌출 0)하므로 자석 아랫면은 모터판 윗면보다 3.7 mm 아래입니다(플러그 머리 높이 고정). 기둥 높이를 계산해 스페이서 없이 칩\~자석 2.0 mm가 되게 했고, 스페이서(기둥당 최대 1.6 mm)로 0.4 mm까지 줄일 수 있습니다. 4 mm 자석은 1.0 mm 스페이서(간격 1.0 mm)부터 시작.

나사: 보유 볼트는 **플라스틱** M2 / M2.5, 전부 6 mm(엔코더 영향 때문에 플라스틱 선택). 플라스틱 볼트는 PLA에 셀프태핑이 안 되므로 M2.5 플라스틱 너트(실측 폭 4.8, 두께 2.0, 8개 이상 보유)를 씀. 너트 홈은 폭 5.1, 두께 2.3, 위쪽 벽 0.8. 타워 모서리 4곳(타워 안쪽에서 밀어 넣음), 기둥 2곳(기둥 9 mm로 굵힘, 가운데 쪽에서 밀어 넣음), 캐리어 밑면 2곳(AS5600). 6 mm 볼트 제약 때문에 스페이서는 기둥당 최대 1.6 mm(간격 최소 0.9 mm). 모터 바닥과 회전자 볼트는 모터 나사 구멍을 그대로 씀. 모터 바닥 구멍은 4 mm 이상 깊이 확인, 모터판 나사 자리 2.5 mm로 3.5 mm만 들어감. 회전자 M2 구멍 깊이는 미확인이라 표시판 3 mm.

출력 파일: foc\_test\_stand\_A1mini\_v4.3mf(전체 최신), foc\_test\_stand\_A1mini\_v4\_자석플러그.3mf(4 mm 자석 플러그 3종만), foc\_test\_stand\_A1mini\_v4\_표시판.3mf(슬롯형 표시판). 자석 홈은 여유 0.2로는 작게 나와(4.2 → 3.7, 6.2 → 5.8) MAGNET\_FIT 0.6 + 입구 모따기 0.4로 수정. 나머지 구멍·너트 홈은 출력 결과 잘 맞아 보정 안 함. 지난 버전 3MF는 old/ 폴더.

## 확인이 필요한 항목

출력 전에 아래 항목을 사용자에게 확인하거나 실측값을 받아 파라미터에 반영합니다.

- [x] AS5600 구멍 중심 간격 실측 → SENSOR\_HOLE\_PITCH 16.0 mm 반영 (구멍 3.6 mm, 가장자리 간격 가로 12.4 / 대각 19.15). M2 나사머리(약 3.8 mm)가 구멍보다 겨우 커서 와셔 사용
- [x] 모터 외경 실측 34.4 mm → MOTOR\_D 반영
- [x] AS5600 헤더 핀: 칩과 같은 면에 있었음 → 칩 반대편으로 다시 납땜하기로 함
- [x] 모터 바닥 고정 홀: M2.5, 가장자리 간격 가로 11.6 / 대각 17.2 → 홀 원 지름 약 19.8 mm
- [x] 모터 중공축 내경 4.7 mm(축과 같이 회전), 바닥 돌출 0, 모터 높이 14 mm, 회전자 M2 구멍 가장자리 간격 가로 7.2 / 대각 10.7
- [x] 자석: AS5600 동봉 4 × 1.9 mm를 기본으로 사용 (6 × 2.5 mm도 보유)
- [x] CadQuery 2.8로 foc\_test\_stand.py 실행 확인 (Google Drive 밖의 임시 venv 사용)
- [ ] 출력 후 끼워 맞춤(포켓, 플러그 압입, 슬롯) 상태 → 공차 TOL 조정

주의사항: 자석 중심이 칩 중심에서 어긋나면 각도가 비선형으로 읽히므로, 캐리어를 체결하기 전에 정렬을 확인합니다. AS5600 값이 고정된 채 변하지 않는 증상이 흔하니 처음엔 모터 없이 각도 읽기부터 확인합니다.

## 다음 단계와 이후 프로젝트

바로 할 일은 위 확인 항목을 반영한 뒤 거치대를 출력해 조립하고, AS5600 각도 읽기와 개루프 회전을 테스트하는 것입니다.

1. 실측값 반영 후 foc\_test\_stand.py 재실행, STEP·STL·3MF 재생성
2. Bambu Studio에서 A1 mini + PLA, 0.2 mm 레이어, 벽 3겹, 채움 20\~25%, 서포트 없음으로 출력
3. 맞는 자석 플러그 선택 → 모터판에 모터 고정 → 스페이서로 센서 간격 1\~2 mm 조정
4. 펌웨어(SimpleFOC 등)로 각도 읽기 → 전압 모드 토크/위치 제어 테스트

이후 프로젝트 후보 (ESC1 1장 = 모터 1개 기준):

| 후보 | 적합도 | 메모 |
| --- | --- | --- |
| 햅틱 노브 (SmartKnob류) | 가장 좋음 | 저속·토크 제어라 ESC1·AS5600 약점이 적음. 원본은 ESP32 일체형이라 하우징은 새로 설계 |
| 리액션 휠 / 자평형 뢸로 삼각형 | 가능 | MPU6050(0x68)과 AS5600(0x36)을 같은 I2C 버스에 연결 가능. 원본은 ESP32 일체형 PCB |
| 3D 프린트 감속기 액추에이터 | 가능 | Hackaday의 ESC1 + 프린트 감속기 사례는 5008급 모터라 2804에 맞게 축소 필요 |
| 2륜 밸런싱 로봇 (MBt2) | 어려움 | 모터 2개 → ESC1 2장 + 보드 간 CAN/UART 통신 필요 |
