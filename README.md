## 기록 규칙

1. **단위**: 실험(또는 공부 주제) 하나 = 글 하나. 몰아서 쓰지 않는다.
2. **위치와 이름**: `log/YYYY-MM-DD-제목.md` (예: `log/2026-08-02-closed-loop-position.md`).
   이미지·그래프는 `log/img/`에 넣고 글에서 상대경로로 링크.
3. **형식**: [log/_template.md](log/_template.md) 복사해서 시작.
   "뭘 하려고 했나 → 뭘 했나 → 막힌 것과 해결 → 배운 것" 순서. 막힌 과정이 본편.
4. **타임라인 갱신**: 글을 올리면 이 README 타임라인에 한 줄 추가 (최신이 위).
5. **코드·데이터**: `projects/` 아래 해당 프로젝트 폴더에 커밋하고 글에서 링크.
   데이터는 선별해서 커밋 (원시 로그 전체 X, 그래프 재현에 필요한 것만).
6. **실패도 기록**: 안 된 튜닝, 태워먹은 부품, 잘못 짚은 원인 전부.
   포트폴리오는 성공담이 아니라 문제 해결 서사다.
7. **커밋 메시지**: `log: 2026-08-02 클로즈드루프 위치 제어` / `p1: 엔코더 캘리브레이션 코드` 식으로
   접두어(log/p1/p2/…/notes)를 붙인다.
8. **"되게 했다"에서 멈추지 않는다**: 왜 되는지 설명이 붙어야 글 완성.
