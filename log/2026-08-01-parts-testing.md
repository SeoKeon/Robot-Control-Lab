# 2026-08-01 도착 부품 테스트 — 전원공급장치와 멀티미터
1. 브래드 보드에 전원공급장치 5v 2a 새팅
2. 집에 있는 간단한 쿨러를 연결하여 동작 확인 함
3. 5v -> 7v로 올려서 회전수가 빨라지는지 확인
4. 멀티미터로 확인 했을때 최대측정 0.2A, 200mA로 설정 했을 때 40mA 측정 됨. 5v, 7v 모두 비슷하게 나왔음
5. 전압 출력은 병렬로 회로와 회로 끝을 확인하여 전원공급 장치가 정상적으로 전압을 주는 것을 확인
6. 전류는 위(4.)에 설명대로 직류로 연결 후 측정 진행함
7. 멀티미터의 경우 전압 측정은 저항이 매우 높아 멀티미터쪽으로 오는 전류가 최소화 됨. 따라서 기존 회로에 영향을 최대한 주지 않을수록 좋은 멀티미터라고 함.
8. 멀티미터의 전류 측정의경우 회로에 영향을 최대한 안끼치기 위해 저항이 0임. I = V/R 이기 때문에 저항이 없는 회로를 측정하면 전류가 확 튈 수 있음
이때 전원 공급장치의 전류 공급 한계(limit)을 걸어놔야 그나마 안전함.
9. 전원 공급장치에는 C.V, C.C, OCP 라는 용어가 있었음
	- C.V : 회로에서 요구하는 전류를 공급할 준비가 된 상태 -> 확인해보니 전압을 일정하게 유지하는 것을 의미함
	- C.C : 전원 공급장치에서 보낼수있는 전류 한계에 도달한 상태 (다시 확인해보니 전압 0에 가까이 낮춰서 전류 리밋을 유지하는 기능인것같음) -> 확인해보니 전류를 일정하게 유지하는 것을 의미함. 저항이 너무 낮아서 전류가 확 튈때 전압을 그만큼 낮추어 전류를 고정해줄 수 있다는 장점 이 있음. 이를 활용하여 어디서 회로가 잘못됐는지 디버깅하는데에 활용할 수 있음
	(Gemini : C.C 모드: 전원을 끄지 않고 전압을 0V 근처로 떨어뜨리면서 **안전한 전류(예: 100mA~200mA)**만 계속 흘려줍니다.)
	- OCP : 전류 한계 보다 더 높은 전류를 요구하게 되었을 때 전압을 차단함
이번 테스트 진행 중 실수로 저항이 없는 회로에 멀티미터 전류를 측정 했음.
이때 전류 한계는 0.2A로 지정. 이때 저항이 없으므로 전류가 폭주하여 OCP 경고가 뜨며 전원공급장치에서 볼테이지 에러가 뜨며 전압공급이 중단 됨.
AI한테 물어보니 실제 회로 단락 문제를 찾을 때는 OCP를 켜놓는 것 보단 C.C 한계를 활용하여 찾는게 더 수월하다고함. 
이유는 전원이 바로 차단되어버리면 디버깅이 어렵기 때문이라고 함.
