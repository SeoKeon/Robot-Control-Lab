# 2026-10-10 dq 전류 관측 — 각도 지연 1.7 ms 를 찾아 절반으로 줄이기

## 뭘 하려고 했나

[전류 센싱](2026-10-10-current-sense-bringup.md)이 정지 벡터에서 맞는 걸 확인했다.
전류 루프로 가기 전에, 지금의 전압 모드 정류를 돌리면서 세 상 전류를
Clarke → Park 로 **id, iq** 로 바꿔서 기대대로 나오는지 본다.

- **id** — 자석 방향 성분. 토크를 안 만들고 열만 낸다. 벡터를 90도 앞에 세웠으니 0 이어야 한다
- **iq** — 자석과 직각인 성분 = 토크. 누르면 커져야 한다

## 뭘 했나

### 1. 손 안 대는 주행 — iq 는 맞는데 id 가 0 이 아니다

| 구간 | rpm | id (mA) | iq (mA) | iq 샘플 σ |
|---|---|---|---|---|
| 저속 정방향 (m=0.25) | 208 | +32 | +26 | 30 |
| 정방향 (m=0.30) | 249 | **+45** | +31 | 29 |
| 역방향 (m=0.30) | −249 | **+43** | −31 | 29 |

iq 부호와 크기는 맞다. 샘플 하나의 σ ≈ 30 mA 는 예측(1 count = 29 mA)과 같다 —
전류 루프가 매 주기 보게 될 노이즈다. 그런데 **id 가 iq 보다 크다.**

단서: **방향을 바꿔도 id 부호가 + 그대로다.** 캘리브레이션 오프셋이 틀렸다면 방향에
따라 부호가 뒤집혀야 한다. 그러니 오프셋 문제가 아니라 **속도 때문에 생기는 효과**다.
후보는 권선 인덕턴스와 각도 지연. 둘 다 정지하면 사라진다.

### 2. 브레이크 테스트 — 멈추면 id 가 0 이 된다

| 속도 구간 | rpm | id (mA) | iq (mA) |
|---|---|---|---|
| **정지 (꽉 잡음)** | 2.9 | **0.6** | **159** |
| 저속 | 29 | 5.2 | 146 |
| 중속 | 137 | 21.3 | 94 |
| 무부하 | 249 | 44.7 | 32 |

- 정지 시 id ≈ 0, iq 159 mA (계산 Vq/R = 1.8 V ÷ 10.5 Ω = 171 mA 의 93%)
  → **각도·오프셋·Clarke·Park 는 정확하다**
- id 는 속도에 비례 (약 0.18 mA/rpm)

두 가설에 숫자를 넣었다.

- **인덕턴스**: `id = ω·L·iq / R`. 구간마다 L 을 역산하면 18 → 24 → 81 mH 로 들쭉날쭉.
  모터의 L 은 고정이므로 **기각**
- **각도 지연 Δ**: 벡터가 Δ 만큼 덜 앞서서 d축 전압 `V·sinΔ` 가 생기고, Park 도 Δ 만큼
  돌아간 축에서 계산된다. 합치면 `id_측정 ≈ Δ·(V/R − iq)` — iq 와 무관하게 속도에 비례.
  **데이터와 맞는다.** 249 rpm 에서 역산하면 **Δ ≈ 18도(전기) ≈ 1.8 ms**

1.8 ms 는 AS5600 내부 slow filter 기본값(16배, 스텝 응답 약 2.2 ms) + I2C 와 맞는다.

### 3. 필터 비교 — 가설 확인

`bsp_as5600_set_filter()` 로 CONF 레지스터(0x07, 휘발성)의 SF/FTH 를 바꿔가며
같은 조건(m=0.30 정방향)으로 돌렸다.

| 설정 | CONF | 정지 각도 σ | rpm | id (mA) | iq (mA) | 역산 지연 |
|---|---|---|---|---|---|---|
| A: SF=16x (기본) | 0x0000 | 0.5 count | 250 | 43.3 | 30.9 | 17.7도 = **1.68 ms** |
| B: SF=2x | 0x0300 | 0.4 count | **262** | **24.1** | 21.2 | 9.2도 = **0.83 ms** |
| C: SF=16x + FTH=6LSB | 0x0400 | 0.5 count | 262 | 24.8 | 21.7 | 9.5도 = 0.87 ms |

## 막힌 것과 해결 과정

### "id ≠ 0" 을 보고 바로 오프셋을 의심하지 않은 이유

가장 먼저 떠오르는 원인은 캘리브레이션 오프셋이다. 하지만 오프셋 오차 ε 는 정방향에서
`−sin ε`, 역방향에서 `+sin ε` 의 d축 전압을 만든다 — **부호가 뒤집혀야 한다.** 역방향도
같이 돌려본 덕에 오프셋을 다시 재는 헛수고 없이 바로 속도 의존 효과로 좁혔다.

### 가설 두 개를 같은 데이터로 가르기

인덕턴스 가설은 `L` 이라는 **고정되어야 할 상수**를 예측한다. 역산했더니 상수가 아니었다.
가설이 숨은 상수를 예측하면, 그 상수가 정말 일정한지가 가장 날카로운 검증이다.

## 배운 것 / 다음 할 것

- **필터를 빠르게 하니 지연이 절반**(1.68 → 0.85 ms), **같은 전압에서 속도가 올랐다**
  (250 → 262 rpm). 18도 늦을 때 실제 앞섬은 72도였다 — 각도 정확도가 곧 토크다
- **이 칩은 정지 노이즈가 1 count 미만**이라 빠른 필터의 노이즈 손해가 안 보였다.
  "필터는 노이즈와 지연의 맞교환"이 일반론이지만, 실제로 손해가 있는지는 재봐야 안다
- **B 를 고른다.** B 와 C 의 결과는 같지만 C 는 속도에 따라 필터가 전환돼 지연이
  일정하지 않다. 남은 지연을 보정하려면 지연이 **일정해야** 한다
- 남은 0.85 ms ≈ 칩 필터 0.29 ms + I2C 약 0.5 ms. 필터로는 더 못 줄인다

### 다음

1. 부팅 시 AS5600 을 SF=2x 로 설정
2. **각도 외삽**: θ_보정 = θ + ω·0.85 ms. 무부하에서 id → 0 이 되는지 확인
