# 2026-10-10 속도 루프 — 눌러도 속도를 지킨다 (p1 완료)

## 뭘 하려고 했나

[전류 루프](2026-10-10-current-loop-foc.md)로 토크(iq)를 정확히 낼 수 있게 됐다. 그런데 전류
루프만으로는 무부하에서 토크를 주면 전압 한계(360 rpm)까지 가속해 버린다. **속도를 명령하면
필요한 토크는 제어기가 알아서 찾는** 바깥 루프를 얹는다. p1 의 완료 기준이다.

```
속도 지령 ─▶ 속도 PI ─▶ iq 지령 (±150 mA) ─▶ 전류 루프 ─▶ 모터
     ▲                                                     │
     └──────────── 엔코더 차분 속도 (5 ms 필터) ◀────────────┘
```

## 뭘 했나

### 설계 — 관성과 토크 상수로 게인 정하기

플랜트: `J·dω/dt = Kt·iq − 부하`. 전류 루프가 수 ms 로 지령을 따라가니, 속도 루프 입장에서
전류 루프는 "iq 지령 = 즉시 나오는 토크"로 본다(대역폭 분리).

| 값 | 크기 | 출처 |
|---|---|---|
| J | 약 5e-6 kg·m² | 전류 루프 가속 데이터 역산. 오늘 역방향 계단(iq 한계에서 10 ms 동안 193 rpm 감속)으로 다시 계산해도 약 6e-6 |
| Kt | 1.5 · 7 · ψ ≈ 0.086 N·m/A | ψ = 8.14 mV·s |
| Kp | J·ωc / Kt | 대역폭 ωc 를 정하면 나온다 |
| Ki | Kp · ωc / 4 | 적분 영점을 ωc 의 1/4 에 |

추가: iq 지령이 한계(±150 mA)에 닿으면 오차가 한계를 더 미는 방향일 때 적분을 멈춘다
(anti-windup). 전류 루프의 전압 제한도 **d축 우선**으로 바꿨다 — |Vd| 를 먼저 지키고 남는
전압 안에서 Vq.

### 1. 첫 계단 응답 (5 Hz) — 평균은 맞는데 출렁인다

| 지령 | 평균 | 100 ms 평균의 sd | 범위 |
|---|---|---|---|
| 100 rpm | 99.9 | 28.8 | 50 ~ 154 |
| 200 rpm | 199.3 | 26.3 | 150 ~ 227 |
| −150 rpm | −150.3 | 32.4 | −194 ~ −96 |

출렁이는 주기가 속도와 상관없이 **정확히 기계 한 바퀴**였다(100 rpm 0.6 s, 200 rpm 0.3 s,
150 rpm 0.4 s). 느려질 때 iq 가 커진다(8 → 41 mA) → 엔코더 착시가 아니라 **회전 위치마다 다른
실제 부하**를 루프가 맞받는 중이다(엔코더 비선형 ±1도로는 속도가 1~2% 밖에 안 흔들린다).

### 2. 대역폭 비교 (`v`, 100 rpm)

| 대역폭 | Kp [mA/(rad/s)] | 평균 | sd | 범위 | iq sd |
|---|---|---|---|---|---|
| 5 Hz | 1.83 | 99.5 | **52.1** | −2 ~ 168 | 11.8 |
| 10 Hz | 3.67 | 100.3 | 12.1 | 73 ~ 127 | 6.4 |
| 15 Hz | 5.51 | 100.1 | **5.0** | 92 ~ 112 | 6.7 |

- 5 Hz 에서는 이번에 한 바퀴마다 **거의 멈췄다**(0.6 s 간격으로 rpm ≈ 0)
- iq 출렁임은 게인과 무관하게 남는다 — 부하 토크는 그대로고, 게인이 높을수록 같은 토크를
  **더 작은 속도 오차로** 낸다. 15 Hz 를 기본으로
- 15 Hz 정지 구간에서도 노이즈 문제 없음 (rpm sd 0.4, iq sd 0.8 mA)

### 3. 브레이크 테스트 (`w`, 150 rpm, 15 Hz)

```
0.4 s       잠깐 누름     65 rpm, iq 119 mA   → 0.1 s 안에 복구
2.6~4.2 s   누름         5~50 rpm, iq 150 (한계) — 한계 토크(약 13 mN·m)를 넘어 밀림
4.3 s       놓음         210 → 158 → 150 rpm (0.2 s)
5.2~10.7 s  꽉 잡음      rpm 0, iq 150.0 mA, id ±1 mA, m 29%
11~13 s     여러 번 누름  매번 0.2~0.3 s 안에 복귀
```

**anti-windup 확인**: 1.6 초 한계에 붙어 있다가 놓았을 때 210 rpm 까지만 튀었다. 적분을 계속
했다면 Ki·오차·시간 ≈ 0.13 × 15 × 1.6 ≈ 3 A 어치가 쌓여, 놓는 순간 전압 한계 속도까지
튀고 한참 못 내려왔을 것이다.

### 4. 1 ms 계단 응답 (`s`, 15 Hz, 송신 수정 후)

| 계단 | 10→90% 상승 | 최고값 | 오버슈트 | ±10% 안착 |
|---|---|---|---|---|
| 0 → 100 | 4 → 17 ms | 154 @ 73 ms | 54% | 291 ms |
| 100 → 200 | 7 → 15 ms | 246 @ 35 ms | 46% | (한 바퀴 출렁임 탓에 300 ms 안에 안 들어옴) |
| 200 → −150 | 6 → 21 ms | −212 @ 33 ms | 18% | 41 ms (iq 한계 −150 mA 를 약 8 ms 씀) |
| −150 → 0 | 6 → 18 ms | 20 @ 26 ms | 13% | 32 ms |

정상상태 (100 ms 평균, 처음 0.3 s 제외): 100.1 / 200.0 / −149.9 / 0.0 rpm, sd 6~8 rpm.
루프 속도 전 구간 1930~1950 Hz.

## 막힌 것과 해결 과정

### 로그를 찍는 동안 제어 루프가 멈춰 있었다

브레이크 데이터를 보다 루프 속도가 단계마다 **첫 100 ms 만 1940 Hz, 그 뒤로 1810 Hz** 인 게
눈에 걸렸다. 첫 구간 앞에는 로그 줄이 없다 → 로그 출력이 루프 시간을 먹는다.

```
115200 baud = 1바이트 약 87 µs.  로그 한 줄 약 70 B → 약 6 ms 블로킹
150 rpm 에서 6 ms = 기계 5.4도 = 전기 38도.  그동안 전압 벡터는 옛 각도에 고정, 전류 루프도 정지
```

100 ms 마다 6 ms 씩 제어가 끊긴 셈이다(전류 루프 실험도 같은 조건이었다). bsp 에 **2 KB 송신
큐 + USART2 TXE 인터럽트**를 넣고 루프가 도는 동안만 켰다. 수정 후 1930~1950 Hz 로 일정.
같이 나온 작은 버그: 한글은 UTF-8 로 글자당 3바이트라 printf 버퍼 128 B 에서 머리줄이 잘렸다
→ 256 B.

### 오버슈트가 이론보다 크다 (원인 미확정)

PI + 관성 플랜트, 적분 영점 ωc/4 이면 이론 오버슈트는 **13.5%**(최고점 t = 4/ωc ≈ 42 ms)다
([노트](../notes/2026-10-10-speed-loop-cascade-design.md) §4). 감속 계단(13~18%)은 이론과
맞는데, 가속 계단은 46~54%. 후보:

- **속도 필터 5 ms** — 15 Hz 에서 위상 약 25도 지연 → 위상 여유 감소 → 더 출렁인다.
  기록된 속도 자체도 필터 뒤 값이라 실제 최고점은 더 높다
- **회전 위치마다 다른 부하** — 0 → 100 계단은 25 ms 에 109 rpm 까지 갔다가 40 ms 에 43 rpm 으로
  떨어졌다(iq 는 + 인데 감속 → 부하 약 4 mN·m). 걸리는 지점을 지나며 생긴 흔들림이 섞였다

계단 지령 자체가 PI 영점을 직접 때린다는 것도 원인의 하나다. 실제 시스템은 지령을 램프로
주거나(궤적 생성 — 위치 루프 단계 주제) 비례 항을 측정값에만 거는 구조(setpoint weighting)를
쓴다. 지금은 기록만 해둔다.

## 배운 것 / 다음 할 것

- 게인은 "감"이 아니라 **측정한 J, Kt 와 원하는 대역폭**에서 나온다. 그리고 결과(대역폭 비교)로
  검증한다
- 대역폭을 정하는 건 **노이즈 vs 외란 억제**의 거래다. 이 모터는 한 바퀴 부하 때문에 5 Hz 로는
  부족했고, 15 Hz 에서도 노이즈는 문제없었다
- 데이터에 이상한 숫자(1940 vs 1810)가 있으면 지나치지 말 것 — 다른 모든 실험에 영향을 주던
  결함이 거기 숨어 있었다
- 한 바퀴 부하의 정체: 모터를 손으로 천천히 돌려 걸리는 지점 확인 (지그 접촉? 자석 홀더?)
- **다음: 위치 루프** — 위치 오차 → P(D) → 속도 지령. 계단 지령 대신 가감속 프로파일
