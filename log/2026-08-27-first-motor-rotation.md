# 2026-08-27 모터 첫 회전 — 오픈루프 왕복 스윕

## 뭘 하려고 했나

2804 짐벌모터에 처음으로 전류를 흘려 돌리는 것. 전류 센서도 엔코더도 없이,
전기각을 강제로 지정하는 **오픈루프**로. 이게 되면 3상 PWM·데드타임·배선이
전부 검증되고, 그 위에 전류 센싱과 FOC 를 쌓는다.

같은 날 오전에 p0(시리얼 hello)를 끝냈기 때문에 **모든 진행을 시리얼 로그로
보면서** 할 수 있었다 — UART 를 모터보다 먼저 뚫은 이유가 이것.

## 뭘 했나

### 준비 — 통전 전에 확정한 것들

| 항목 | 값 | 출처 |
|---|---|---|
| 3상 PWM 핀 | U: PA8/PC13, V: PA9/PA12, W: PA10/PB15 | UM2516 Table 4 |
| PWM | 20kHz center-aligned, ARR=4249 | 170MHz ÷ (2×4250) |
| **데드타임** | **1µs (DTG=149)** | L6387 데이터시트에서 유도 |
| 변조 방식 | 사인 (duty = 0.5 + 0.5·m·cosθ) | bsp_pwm_set_vector() |
| 전원 | 12V, **전류 리밋 0.8A** | 상간 21Ω → 최악 0.57A |

안전 구조를 먼저 확인했다. 이 보드는 **TIM1_BKIN 이 MCU 에 연결돼 있지 않고**
(하드웨어 과전류 차단 없음), **게이트 드라이버 EN 핀도 없다** (6개 PWM 이 전부).
→ 전원공급장치 리밋이 유일한 보호장치, 출력을 끊는 유일한 수단은 MOE 비활성.

### (a) 정지 벡터 — 회전 없이 3상 검증

고정 전기각으로 벡터를 세워 로터가 그 방향으로 붙는지만 봤다.
60도씩 12스텝(전기각 2바퀴), m=0.30, 스텝당 600ms 유지.

- 12스텝 모두 진행, **리셋 없이 완주** → 션트-스루 없음 = 데드타임 검증
- 로터가 스텝마다 딸깍 이동. 단 총 이동 약 70도 (기대 94도) — 아래 참고
- PWM off 순간 반대로 살짝 움직임 — 아래 참고

### (b) 왕복 스윕 — 첫 회전

**모터 선이 로터와 함께 도는 구조라 기계각 약 180도가 한계.** 연속 회전을
포기하고 기계각 ±50도 왕복으로 설계를 바꿨다. 전기각을 500Hz 로 갱신하며
전기 200 → 3200 deg/s 5단계.

결과:
- 약 100도 왕복 (설계값 그대로)
- 전류 0.2A 미만 (계산 0.22A 와 일치)
- 5단계 전부 추종, 덜컹임·탈조 없음
- **오픈루프 한계는 기계 457 deg/s (76 rpm) 이상** — 이번 범위에선 못 찾음

## 막힌 것과 해결 과정

### CubeMX 의 "Output Compare" 는 PWM 이 아니다

첫 생성에서 채널 모드를 `Output Compare CH1 CH1N` 으로 골랐다.
생성된 코드를 보니:

```c
sConfigOC.OCMode = TIM_OCMODE_TIMING;   // "Frozen" — 출력 핀에 아무 영향 없음
```

`PWM Generation CH1 CH1N` 을 골라야 `TIM_OCMODE_PWM1` 이 나온다.
목록에 두 항목이 나란히 있어 헷갈리기 쉽다. **생성 후 OCMode 를 꼭 확인할 것** —
이대로 보드에 올렸으면 "PWM 은 켰는데 아무 파형도 안 나오는" 상태로 헤맸을 것이다.

### PC13 은 GPIO 속도를 Low 밖에 못 고른다

CubeMX 에서 PC13(CH1N)만 High 선택지가 없었다. PC13/14/15 는 백업 도메인
(RTC/TAMP) 쪽 핀이라 구동 능력이 제한된다 — 버그가 아니라 칩 스펙.

문제 안 되는 이유: MCU 는 MOSFET 게이트가 아니라 **L6387 의 로직 입력**(수 pF)만
흔든다. 게이트는 드라이버가 sink 400mA 로 구동한다. MCU 슬루율은 데드타임
예산에서 무시 수준. → 6핀 전부 Low 로 통일 (채널 간 skew 없애는 쪽이 중요).

### 스텝 추종 부족 — 토크가 코깅에 빠듯

(a)에서 11스텝 전진 기대치 94도(= 11 × 8.57도)에 실측 약 70도.
m=0.30(약 0.15A)의 토크가 코깅+마찰을 이기기에 빠듯해 로터가 명령각을
다 못 따라간 것. **m=0.45 로 올리니 (b)에서 완전 추종.**

### PWM off 때 역방향 미동 — 고장이 아니라 물리

전류가 끊기면 유지 토크가 사라지고, 로터는 **가장 가까운 코깅 디텐트로 안착**한다.
12N14P 의 디텐트 간격 = 360/LCM(12,14) = **4.29도**. 그만큼 살짝 움직인 것.
오히려 유지 토크가 실제로 걸려 있었다는 증거다.

## 배운 것 / 다음 할 것

- **전류계가 곧 검증 도구다.** 리밋 0.8A 을 걸어두고 "리셋 없이 완주 + 0.2A 미만"
  이면 데드타임·배선·계산이 다 맞다는 뜻. 스코프 없이도 여기까지 온다
- **기계 제약이 실험 설계를 바꾼다.** 선이 같이 도는 구조 → 연속 회전 불가 →
  왕복 스윕. 확인 항목(추종·탈조)은 그대로 다 확인됐다
- 오픈루프는 되지만 낭비다 — 각도를 모르니 항상 최대 여유로 전류를 흘려야 하고,
  로터가 어디 있는지 몰라 최적 토크각(90도)을 못 잡는다. **이게 FOC 를 하는 이유**
  (이론은 notes 참고)
